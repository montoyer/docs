# QCM EPSO/AD/428/26

## EPSO audit drill

One hundred original multiple-choice items written against the Annex II typical duties of open competition **EPSO/AD/428/26 — Administrators (AD 7) in the field of audit**. Answer each question, then open the collapsible to see the correct option and why.

{% hint style="warning" %}
These are practice items, not predictions. Nothing here is taken from, or claimed to resemble, a real test paper.
{% endhint %}

### The test being simulated

| Parameter    | Notice                            |
| ------------ | --------------------------------- |
| Questions    | 30                                |
| Time         | 40 minutes                        |
| Language     | Language 2                        |
| Pass mark    | 15/30                             |
| Use of score | Ranking among candidates who pass |

That works out at **80 seconds per question**. Because the score ranks you as well as passing you, speed has real value.

### How the pages divide

Each paper takes every third item from the bank, so all eleven duty clusters stay proportionally represented. The four pages together contain all 100 items, each exactly once.

| Page         | Items | Format            |
| ------------ | ----- | ----------------- |
| Paper A      | 30    | Timed, 40 minutes |
| Paper B      | 30    | Timed, 40 minutes |
| Paper C      | 30    | Timed, 40 minutes |
| Reserve pool | 10    | Untimed           |

The number in brackets after each question, such as `(Q47)`, is the item's number in the full bank, so you can cross-reference.

### How to use it

1. Sit a paper under real conditions : 40 minutes, no notes, no pausing.
2. Answer every question. There is no negative marking.
3. Open the answers only once you have finished, and tally your score.
4. Note which cluster each wrong answer came from. Two or more errors in one cluster is a signal, not noise.

{% hint style="info" %}
Correct answers are spread evenly across A, B, C and D : 25 each across the bank. Guessing by letter position earns nothing.
{% endhint %}
